# Restrauque mobile screen reference exports

These are individual reference images split out from the generated 8-screen concept, plus a new feedback-screen vector mockup. They are visual references to rebuild the real responsive UI, not production code and not an editable Figma document.

Files 01–08 are crops from the concept image and scaled 2x for easier viewing. The generated concept contains example names/prices/order states; replace those with live API data and verified product design. File 09 feedback is a vector SVG and PNG preview. The SVG can be imported into Figma and most elements remain vector-editable.

## Bring into Figma
1. Open your Figma design file.
2. Create a page called `Customer Ordering — References`.
3. Drag each PNG onto the canvas to keep one reference per screen.
4. Import `09-feedback-after-completion.svg` for a vector reference.
5. Rebuild the actual screen with editable auto-layout components, constraints, and theme variables; don't use full-screen PNGs as the finished application.
